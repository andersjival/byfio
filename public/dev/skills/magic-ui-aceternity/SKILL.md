# ✨ Skill: Magic UI & Aceternity UI — Efectos de Alto Impacto para One-Pages

Inspirado en los repositorios de componentes de nueva generación **Magic UI** (`magicuidesign/magicui`) y **Aceternity UI**, este estándar resuelve la capa de deslumbramiento visual que diferencia a una landing page corporativa plana de una experiencia memorable y de alta conversión.

---

## 🚀 1. Componentes Clave de Alto Impacto

1. **Border Beam (Haz de Luz en Bordes):**
   - Un haz de luz continuo o reactivo que recorre el contorno de una tarjeta o botón destacado para atraer la atención visual sin ser molesto.

2. **Spotlight Cards (Iluminación Focal Dinámica):**
   - Tarjetas que reaccionan al cursor o al foco con un resplandor radial suave (`radial-gradient`), revelando texturas y detalles sutiles.

3. **Shimmer Buttons (Botones con Destello):**
   - Botones de llamada a la acción con un barrido luminoso sutil que transmite dinamismo e invita al clic.

4. **Mesh Gradients & Ambient Glows:**
   - Orbes de iluminación desenfocada (`blur-3xl`) que aportan profundidad tridimensional a las secciones Hero oscuras o claras.

5. **Bento Grid Interactivo:**
   - Cuadrículas con hover reactivo donde cada cuadrante destaca una capacidad tecnológica con micro-animaciones específicas.
